process

Write it down, then let the agent build.

The unusual part is not that agents write code. It is that the docs are the control plane — PRD, domain, contract, ADRs, and plans that exist only while work is in flight.

how it was made

Agents write. I review. The product still has to work.

Vynno is a daily-driver focus timer and a lab for working with AI. Two goals, side by side: something I will actually use, and a clearer sense of what to delegate, what to read, and how to keep a product coherent.

  1. 01 plan

    Agents help shape the work. I decide what ships. Design tokens, brand, and the session model stay human decisions.

  2. 02 implement

    Agents write most of the code. The stack does not change for convenience: SvelteKit, TypeScript, Go, the same dark IDE chrome.

  3. 03 review

    I read the diff. If it would not survive a workday on the timer, it does not land. Agent output is held to the same rules as everything else.

Write first

Pick the document the change belongs in. Then implement. Then keep the docs true. Plans are deleted when the work ships; git history is the archive.

  2. →
  3. 02 Pick the doc
  4. →
  5. 03 Agent implements
  6. →
  7. 04 Read the diff
  8. →
  9. 05 Docs stay true

  • PRD

    Vision, goals, non-goals. Not stack, not field names.

  • domain

    Entities, lifecycles, invariants the server must enforce.

  • contract

    Paths, DTOs, status codes. Amend this before the handler.

  • ADR

    Expensive or irreversible choice. Keep the file; amend, don’t rewrite.

  • plan

    In-flight only. Move facts into the canonical docs, then delete it.

Who owns what

human

  • What ships, and whether it survives a workday
  • Brand, session model, stack, repository boundary
  • Accept or reject the ADR
  • Read the diff

agent

  • Most of the code, tests, and runbooks
  • ADR and plan drafts from the templates
  • Follow AGENTS.md and the contract
  • Read one account’s history through the local MCP. Cannot start, stop, or edit a session from it.
  • Do not invent endpoints or rewrite history

Decisions that stuck

A curated set. Each card is the decision in one line; open it for context and the rejected alternative. Full indexes stay on GitHub.

FE 0001 SvelteKit, TypeScript, Tailwind accepted

Dense, keyboard-first UI in a frontend-only repo. SvelteKit maps routes to screens; Tailwind maps onto the design tokens.

Not React/Next, Vue, or plain Svelte without Kit.

ADR-0001

FE 0002 · API 0002 Separate repositories accepted

UI and API do not share a repo, a process, or a package. The shared language is the HTTP JSON contract.

Not a full-stack monorepo, not a BaaS from day one.

Frontend · API

FE 0010 DTO-first HTTP JSON accepted

Domain types stay UI-facing. Wire JSON is Valibot schemas plus mappers. No SvelteKit remote functions.

UI names like isArchived do not leak onto the wire.

ADR-0010

FE 0011 SSR and a same-origin BFF accepted

First paint comes from +layout.server.ts. Stores are request-scoped on the server. The browser calls /v1; Kit forwards the cookie.

Not a client-only SPA with module singletons.

ADR-0011

FE 0014 · API 0011 Local production, no cloud accepted

Daily driver is this machine: Caddy on vynno.localhost, adapter-node, compiled API, Compose Postgres. Availability is “the laptop is on.”

A public host would be a new ADR, not a silent deploy.

Frontend · API

FE 0021 Insights uses an explicit civil range amended

Week, 2 weeks, month, or custom From–To. Prev/next shift the grain. Range is view-local — leaving the screen resets to this week. The donut header compares with the same elapsed span of the previous period.

A past range reads /stats/days instead of paging history. No chart-shaped endpoint.

ADR-0021

FE 0022 Logs list filters accepted

Date presets plus custom, multi-select projects and activities. Empty selection means all. Combined with search by AND.

View-local. The project dossier reuses the activity facet.

ADR-0022

FE 0023 Logs grouped-by-task layout accepted

Entries stays the default. Grouped merges same-ticket (else same project + note) sessions inside a day, with count and total duration.

No API change. Expand a summary to the constituent rows.

ADR-0023

FE 0024 · API 0005 Session is a continuous interval accepted

Status is active | stopped. Verbs are start and stop. A break is stop, then start a new session. Duration is wall-clock.

No paused live state, no pausedMs.

Frontend · API

FE 0026 Tabs and devices stay in step accepted

Sibling tabs replay each write over a BroadcastChannel. Another device re-reads the live session when its tab becomes visible. A Stop that loses a race reconciles instead of failing.

Not polling, and not SSE — no new API surface.

ADR-0026

FE 0027 Year heatmap; weekends never break a streak accepted

53 weeks from /stats/days, shaded against the daily target. A streak is days with any tracked time; an untracked weekday ends it.

Not GitHub-style every-day streaks — they reward working weekends.

ADR-0027

API 0001 Go + Gin, domain isolated accepted

internal/domain must not import Gin or the database driver. Handlers stay thin; lifecycle tests do not need HTTP.

Gin binders may decode JSON; they are not the source of truth for contract codes.

ADR-0001

API 0008 HttpOnly cookie, not JWT accepted

Opaque session token, SHA-256 on the server, cookie vynno_session. Login JSON is { profile } only. SPA never sends Authorization.

Bearer exists for curl and tests. XSS cannot read the secret.

ADR-0008

API 0005 One live session, verbs only amended

At most one active row. A session is a continuous interval; stop is the only live verb. Stopped rows are mutable (edit, delete, manual entry).

Do not auto-stop. Do not PATCH status. No pause.

ADR-0005

API 0009 Postgres, sqlc, goose accepted

Durable rows so reload and a second device agree. In-memory is a test double. Migrations are plain SQL, applied at boot.

Not GORM as the source of truth.

ADR-0009

API 0015 SMTP via a Mailer port accepted

Register confirmation and password reset leave through internal/mail. Daily driver is Mailpit. No Resend/SES SDK.

Domain does not import SMTP. Tests use discard.

ADR-0015

API 0016 Read-only MCP for one account accepted

Local stdio in cmd/mcp. One session token, one account, read-only column allowlist. The SPA contract does not change.

Not a stock Postgres MCP — arbitrary SQL, secret columns, every account.

ADR-0016

API 0017 Account prefs, not device prefs accepted

GET / PATCH /me/prefs: daily target and default project follow the user. Theme and locale stay on the device, applied before first paint.

Not fields on the profile, not a free-form key-value blob.

ADR-0017

API 0018 Day totals, computed per request accepted

/stats/days sums tracked time per local date, project, and activity in the client’s IANA zone. The server sums; the SPA shapes.

Not one endpoint per chart, not a rollup table.
